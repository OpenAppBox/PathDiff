# Contributing

Thanks for your interest in PathDiff!

PathDiff's source code is published here so anyone can see how the app works. Development happens within the OpenAppBox team, so:

- **We don't accept pull requests.** Pull requests are closed without review, whatever their content. Please don't spend time on code changes for this repository.
- **We can't help with building or modifying the code.** The Mac App Store version is the only supported way to use PathDiff.

## How you can help

Your reports and ideas shape PathDiff, and we read every one:

- **Found a bug?** [Open a bug report](https://github.com/OpenAppBox/PathDiff/issues/new?template=bug.yml).
- **Missing something?** [Request a feature](https://github.com/OpenAppBox/PathDiff/issues/new?template=feature_request.yml).
- **Anything else?** [Send feedback or a question](https://github.com/OpenAppBox/PathDiff/issues/new?template=feedback.yml).
- **Security problem?** Follow [Security](SECURITY.md) instead of opening a public issue.

See [Support](SUPPORT.md) for what to include in a report.

## Translations

PathDiff is available in 23 languages. If a translation reads wrong or uses an unusual term, a feedback issue quoting the text, where it appears, and your suggestion is very welcome.

## Be kind

Be respectful in issues and comments. Abusive or off-topic content is removed.
