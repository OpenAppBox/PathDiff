# Security

PathDiff reads and writes folders you choose, so we take problems that could expose or damage your files seriously.

## Reporting a problem

Please don't open a public issue for a security problem. Instead, [report it privately](https://github.com/OpenAppBox/PathDiff/security/advisories/new) (Security ▸ Report a vulnerability). Only the OpenAppBox team can see private reports.

Include:

- what the problem is and what it could let someone do,
- the steps or files needed to reproduce it,
- your PathDiff and macOS versions.

We'll confirm we received your report and keep you updated there. Fixes are delivered as PathDiff updates through the Mac App Store.

## Supported versions

Only the latest version on the Mac App Store receives fixes.

## How PathDiff protects your files

- It runs in the macOS App Sandbox and can only reach folders you choose.
- It has no network access.
- Nothing is written until you confirm. Removed items go to the Trash, and changes can be undone or reverted from Sync History.
